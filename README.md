# Digital Wellbeing Dashboard

## Overview

The **Digital Wellbeing Dashboard** is an interactive Power BI project designed to analyze smartphone usage patterns and their impact on users' digital wellbeing.

The dashboard helps identify trends related to:

- Screen time
- Phone unlock frequency
- Daily notifications
- Anxiety levels
- Stress levels
- Focus score
- Digital dependence
- High-risk users

It provides meaningful insights through interactive visualizations and KPI cards.
